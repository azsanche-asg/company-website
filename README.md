# EyeTrustAI website

Static website for https://eyetrustai.com/.

## Development

Serve the repository with any static web server; no build step is required. The main website uses HTML and CSS. `contact.js` prepares a reviewable email draft without submitting or storing enquiries. The existing interactive demonstrations are self-contained HTML files under `demos/`.

## Publishing

GitHub Pages publishes the root of `main`. Keep `CNAME` and `.nojekyll` in place.

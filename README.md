# EyeTrustAI website

Static marketing pages and self-contained product walkthroughs. Shared styles preserve the website's layout. JavaScript supports the interactive walkthroughs and the shared contact/booking dialog.

The contact dialog submits directly to EyeTrustAI's dedicated Cloudflare service. It retains the page context, supports messages and email-confirmed appointments, and opens from the existing contact links. `/contact.html` preserves old links by opening the same dialog. No email application or third-party booking page is required.

The service source and deployment configuration are maintained separately from this public static website. Do not publish private booking data or server credentials here.

The short product examples link directly into the complete guided setup, warm-up, assessment, activation and operating journeys. Evidence pages distinguish computed public-data evaluations from product scenarios and explain their scope.

Research data sources, image attribution and font licenses are retained with the relevant pages and assets.
